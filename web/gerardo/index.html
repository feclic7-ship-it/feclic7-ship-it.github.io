Redes de Computadoras

Aprende de forma clara y moderna qué son las redes, sus tipos y las topologías más utilizadas.

Ver información

¿Qué es una red de computadoras?

Una red de computadoras es un conjunto de dispositivos conectados entre sí con el objetivo de compartir información, recursos y servicios mediante medios físicos o inalámbricos.

Gracias a las redes es posible enviar archivos, navegar por internet, imprimir documentos desde distintos equipos y comunicarse en tiempo real.

Ejemplos de dispositivos en una red:

  • Computadoras
  • Celulares
  • Servidores
  • Impresoras
  • Routers y switches

Tipos de redes

LAN

Red de área local. Se utiliza en casas, escuelas u oficinas pequeñas.

MAN

Red de área metropolitana. Conecta varias redes dentro de una ciudad.

WAN

Red de área amplia. Conecta dispositivos a grandes distancias, como Internet.

WLAN

Red inalámbrica que funciona mediante Wi-Fi sin necesidad de cables.

¿Qué es la topología de red?

La topología de red es la forma en la que se organizan y conectan los dispositivos dentro de una red.

Topología Estrella

Todos los dispositivos se conectan a un punto central, generalmente un switch o router.

Topología Bus

Todos los equipos comparten un mismo cable principal.

Topología Anillo

Los dispositivos se conectan formando un círculo.

Topología Malla

Cada dispositivo puede conectarse con varios equipos para mejorar la comunicación.
